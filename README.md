## 🚀 دليل النشر السحابي في 3 خطوات (Supabase + GitHub + Vercel)

### 1️⃣ الخطوة الأولى: إعداد قاعدة بيانات Supabase (في دقيقتين)
1. سجل دخولك على [Supabase.com](https://supabase.com) وأنشئ مشروعاً جديداً مجانياً (New Project).
2. من القائمة الجانبية في سوبابيز، ادخل على **SQL Editor**.
3. افتح ملف `supabase_schema.sql` الموجود في جذر هذا المشروع، وانسخ كل محتواه والصقه في الـ SQL Editor واضغط **Run**.
4. سيقوم الاسكربت بإنشاء كافة الجداول (Members, Committees, Tasks, Events, Attendance, Evaluations, Complaints) ومستودعات التخزين السحابية (Storage Buckets) وسياسات الأمان والحساب القيادي الرئيسي للأستاذ محمد رمضان تلقائياً.
5. من القائمة الجانبية ادخل على **Project Settings -> API** وانسخ:
   - `Project URL`
   - `Project API Keys (anon public)`

---

### 2️⃣ الخطوة الثانية: رفع المشروع على GitHub
قم بتشغيل الأوامر التالية في مجلد المشروع:
```bash
git init
git add .
git commit -m "feat: production clean launch with Supabase integration"
git branch -M main
git remote add origin https://github.com/YOUR_USERNAME/alexu-volunteers-platform.git
git push -u origin main
```

---

### 3️⃣ الخطوة الثالثة: النشر على Vercel
1. ادخل على [Vercel.com](https://vercel.com) واضغط **Add New -> Project**.
2. اربط مستودع GitHub الذي قمت برفعه للتو.
3. في صفحة الإعداد قبل الضغط على Deploy، افتح قسم **Environment Variables** وأضف المتغيرين:
   - `VITE_SUPABASE_URL` = (عنوان الـ URL الخاص بمشروعك في سوبابيز)
   - `VITE_SUPABASE_ANON_KEY` = (مفتاح الـ Anon Key من سوبابيز)
4. اضغط **Deploy**! 🚀
5. مبروك! أصبح التطبيق يعمل أونلاين على نطاق Vercel السريع مع مزامنة سحابية حية وتخزين لحظي.

## 📋 آلية تسجيل المتطوعين الجدد وتوزيع الصلاحيات
1. يدخل الطالب الراغب في التطوع على المنصة ويختار **«تسجيل متطوع جديد»**.
2. يملأ بياناته الرسمية (الاسم الرباعي، الكلية، الفرقة، الرقم القومي، رقم الواتساب، واللجنة المرغوبة).
3. يصل إشعار عاجل للوحة تحكم القيادة ومستشار الفريق.
4. يدخل مستشار الفريق أو رئيس الفريق إلى **«دليل المتطوعين»** -> قسم **«طلبات الانضمام المعلقة»**.
5. يضغط على **«اعتماد وقبول الطلب»**، ويحدد اللجنة التخصصية والدور المطلوب (عضو / نائب رئيس لجنة / رئيس لجنة).
6. يقوم النظام فوراً بتوليد **الكود التطوعي الرقمي الرسمي** (مثل `OC-101`) وتفعيل الحساب فوراً.
